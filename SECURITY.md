# Security Policy

Ledgerline is a SpecShield Labs internal engineering demonstration. It uses synthetic data only and is not
a production payment system. We still treat security reports seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Email **security@specshield.example** with:

- a description of the issue and its impact,
- steps to reproduce (a minimal proof of concept is welcome),
- the commit or version you tested.

We aim to acknowledge reports within 5 working days and will keep you informed while we fix the issue.

## Supported versions

Only the `main` branch is supported.

## Scope

In scope: code and configuration in this repository, including the CI workflows.
Out of scope: findings that require real payment data (there is none) and social engineering.
